Завдання 1–2 — Стилі шрифтів і тексту

Це перший абзац із вирівнюванням по ширині та відступом першого рядка. Текст написаний чорним кольором розміром 14pt. Стилі CSS дозволяють легко керувати виглядом тексту на сторінці.

Це другий абзац — жирний темно-червоний текст по центру. CSS робить форматування зручним.

Це третій абзац — синій курсив із відступом першого рядка. Можна задавати будь-який колір і стиль написання тексту за допомогою властивостей CSS.

Це четвертий абзац — зелений підкреслений текст вирівняний по правому краю.

Це п'ятий абзац у стилі small-caps — всі літери відображаються як великі, але меншого розміру.

Розділ 1: Контейнер div із синьою лівою рамкою та блакитним фоном. Стиль задано через клас у контейнері style. Це дозволяє забезпечити єдність оформлення всіх розділів документа.
Розділ 2: Контейнер div із помаранчевою пунктирною рамкою та теплим фоном. Завдяки CSS можна швидко змінити вигляд усіх елементів одночасно, просто відредагувавши один стиль.
Розділ 3: Контейнер div із заокругленими кутами та зеленим фоном. Використання класів CSS — найзручніший спосіб забезпечити єдність стильового оформлення документа.
